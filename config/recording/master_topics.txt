# master_topics.txt — topics recorded by golfcart-record.service on the MASTER.
#
# One topic per line. `#` starts a comment, blank lines are ignored. Read by
# scripts/recording/record_unit_exec.sh, which passes them to `ros2 bag record`.
#
# Topic names verified against a running stack on 2026-08-10 with
# `ros2 topic list`. The list this replaced was inherited from
# scripts/rosbag/record_outdoor.sh and had the Velodyne under `top/` and the
# GNSS under `ublox/`; NEITHER NAMESPACE EXISTS HERE, so those entries recorded
# zero messages while still looking correct in `ros2 bag info`. Re-check with the
# audit in docs/multi-machine.md after any sensor kit change.
#
# WHY THE MASTER/ORIN SPLIT: both LiDARs are cabled to the master and their
# clouds are ~30 MB/s each, far past the shared 100 Mb/s LAN. Only the ZED's
# *compressed* stream (~5 MB/s) is small enough to cross it, and even that is
# recorded on the orin instead. Each host therefore records its own sensors to
# its own disk; the orin's ZED topics are deliberately absent from this file.
